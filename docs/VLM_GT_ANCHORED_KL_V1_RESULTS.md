# GT-CE+KL：是否真的提升模型能力

**结论：确认局部Object表现改善；没有达到预设的综合能力提升标准，也未证实GT-CE优于本轮仅KL控制。** 原8门槛5过3败，完整负结果已独立验收，不扩种子/外部，不因接近阈值放宽规则。

## GT-CE这一变化是否有效

相对新fresh仅KL控制，候选Object **−.292398pp（少对1道truck题）**；Text **+.166976pp**，7题升/4题降，95%区间[−.142773,+.499407]跨0。没有证实GTCE保持优于KL。这里同一seed的两个条件不能作两次稳定性重复。

rare的净+.6score来自：QA10996从完整日期改为wednesday（+1）、16105从portland, oregon改portland（+.7），同时15990 $1.00→$1（−.7）、29766 spring→spring water（−.4）。这些真实回答说明答案粒度/措辞匹配占了净收益的重要部分，不能据rare点值推断视觉理解增强，也不据语义直觉改官方评分。

QA24111 brand颜色blue→white，原图白色logo支持这次纠正；Object116694边缘黄色车辆的no→yes也与原图/已锁标签相符。这些是具体实例的支持，不是注意力、机制因果或跨分布证据。全部升降题保留在独立receipt中，不只选成功图。
