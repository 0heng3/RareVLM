## 可用结论与边界

两个真实长尾下游数据集上观察到 CE 头尾取舍与部分固定表示校正改善。单位强度经验 α=1 不通用。iNaturalist 使用 8,142 个科学名原型，绝对准确率有限；没有对其他 prompt、可训练分类头或完整 fine-tuning 作对照，不将低成绩唯一归因于其中某项，也不包装为 SOTA/可部署物种识别产品。

固定 CE 校正不更新当前表示，说明大量净损失可以通过决策干预恢复，不证明表示完全没有变化或损伤。未实测的 ARS、E-PCG、GES 等不能被称为已证伪。CIFAR TailSpec-static 仅属于人工长尾 pilot。

原 iNaturalist 实验核对了 19 份逐图预测/指标、6 个完整 20-epoch checkpoint、3 组初始化/采样配对与文件哈希。共享评估图像和每类仅 3 张评估图的限制见 [协议](PROTOCOL.md)。CPU smoke 是软件执行检查，与本表研究成绩分开。
