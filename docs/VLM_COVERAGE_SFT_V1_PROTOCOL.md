# 原生错误覆盖128 × 重复32：匹配SFT v1

2026-10-21事前登记。上一GRPO只有17题策略信号、训练仅6/32满分，保存曲线主要表现为从未学会。新3072训练池实际生成205低分候选，固定前184原图助手复核得到131支持/53排除或不确定，按原顺序/每target最多2取128，125不同规范化target。53/184不是全池错标率，助手复核不是专家或用户重标注。原始GT、VQA评分、旧Final和失败不改。

## 假设和单变化

在固定正确监督曝光与保持回放下，扩大不同可信错误图像的覆盖，是否比反复学习少量错误更能提高新图问答？只比较普通完整CE的`repeat32`与`coverage128`，不加DPO/GRPO或新模块，不接训任何旧负Final。

128池采用已通过`TRAINING_ADMISSION.json`的原生题，含拼写/目标选择/视觉读数/数字等。先按(error_type, 原目标频次1–5或6–20, 单词/多词)分层，以固定SHA各层选子集、配额合计32；小层至少1，大层按比例分配。候选128题各4次=512困难曝光；控制按同一逐slot分层从32子集中循环取题，共512困难曝光。两组每slot错误类型/频次桶/长短相同，控制每题次数按各层大小而不同，不伪称严格每题16次。身份/难度/视觉token仍可不同，不能将结果全部归因于抽象样本数或称等计算。

两组共用512不同训练图的初始满分回放，各1次，同序同输入；与128错误/新512验证/原64保持无同pixel重叠。每更新4个micro×4QA，replay4/hard4/replay4/hard4，CE按16QA平均；完整64更新/1024曝光，其中512困难+512回放。每题只监督真实GT内容和模板EOS，无postEOS换行。原uniform SFT42起点、语言q/v FP32 LoRA1843200、BF16冻结底座/视觉、冻结FP32输出头、1024视觉预算、dropout0、AdamW lr2e-5/warmup8/线性下降64/weight_decay0/grad clip1均匹配。

本轮固定Final@64，不按分数选中间checkpoint，不自动加步/扫LR/种子。每8步及第1步保存FP32 LoRA/optimizer/RNG；每步追加STEP_METRICS.jsonl，含分源CE、梯度范数、LR、时延、视觉/监督token与累积曝光，修复未来训练仅保留最后一步指标的记录缺口。INPUT_TRACES单独保留实际ID/hash/来源/CE，恢复按断点字节偏移截断。

## 评测与复用

新挖掘时预固定的512验证（单词/多词各256，rare1–5为366、6–20为146）整体原样保留。原始SFT生成已按完整四题批次完成，后续Final保持完全相同batch4边界/图像/问题/1024/raw greedy32。初始512直接复用矿池同条件预测，不称新独立重复/初始模型未见或盲测。

128训练诊断的Final保留原矿池中含这些题的完整4题上下文批次，其他slot只作数值批背景，最终只统计这128题；初始亦直接复用同批矿池预测，不重新分组造成数值路径变化。64保持复用原GRPO研究同原始SFT/batch4预测，Final实际生成；公开训练白名单/预训练重叠未知保持披露。两候选每角色实际生成数为新512+64+固定训练上下文批次，不把上下文非评分题当独立训练纠错。

## 事前联合门槛与预算

候选新512对初始及新repeat32均>=+.5pp且各95%配对图像簇下界>0；rare1–5对初始点值>=+.5pp，single/multi和6–20对初始/新控制均>=−.5pp；64保持对两者均>=−.5pp；128训练满分对初始净增加>=32。报告6000次固定seed20261021图像簇bootstrap、所有改进与退化、频次与长度切片，单checkpoint条件区间，不冒充三seed/主benchmark。

失败停止该配置，不回调数据/比例/label/阈值或追加当前正式集；通过仅支持另登记独立确认/三seed和原正式TextVQA overall/rare及Human保持标准，不自动执行主集或改CV。
