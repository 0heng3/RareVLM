# 原始策略同题采样信号 v1（0训练）

登记于2026-10-20，必须先准备、CPU验证与冻结，再采样。问题来自已完成的真实错误研究：DPO未满分23题中22题正确整段logP仍低于固定负例；固定文本偏好虽相对改善，未转成足够实际决策或验证增益。29条匹配负文本中2条实际生成token路径不等canonical重编码。后者不是标准离线DPO本身的实现违规，但在线策略优化必须保存实际动作，不能用decode/re-encode代替。

本轮只回答：**原始SFT策略在可信困难题上，是否能采出有差异的可评分回答，为在线奖励优化提供必要信号？** 不更新模型，不承诺GRPO提分，不复用负Final继续训练。

## 固定输入和采样

- 原始uniform SFT seed42，沿用decision-trace记录的完整LoRA哈希；BF16底座、FP32 LoRA/冻结FP32输出头、1024视觉预算。原图/问题/提示一致，GT与十人答案只在生成后评分。
- 使用既有人工可见证据审查支持的32道训练错题，顺序完全沿用旧hard_eval；其中原始重新生成已1道满分，不能说32道当前全错。这是曾经训练过的训练池，不是独立评测或全量数据。
- 每题同一prompt独立8路采样（batch8），共256条。temperature=1，top_p=1、top_k=0（关闭截断）、repetition_penalty=1、32新token上限，显式配置不继承隐藏惩罚。每题seed由固定20261020和qid的SHA256得到，单独设RNG；单卡任务，不比较跨硬件bitwise确定性。
- 每条保存原始prompt_ids、实际completion_ids、EOS是否出现、文本评分视图；EOS后batch补位不算动作。达到32token却未EOS时不补结束符，视为长度删失，不进入可用正负对或优势。
- 原始动作直接拼接到原prompt，保留相同pixel/grid；labels只标completion（含实际EOS），不加模板postEOS换行。输出头裁尾依最早有效label位置，而非有效label个数，避免尾部mask导致丢失首答。此新接口不改旧训练源或历史标签。

## 奖励与判据（事前固定）

原十人VQA consensus评分，不替换GT、别名或正常化。奖励r∈[0,1]，满分r>=.999999，低分r<=.3，清晰差>=.7。只在自然结束样本中计算同题均值和样本标准差：A=(r-mean)/(sample_std+1e-4)。这只展示GRPO的组内信号，不计算任何策略梯度或优化器更新。

事前准入必要条件：32题中至少16题同时有自然结束的满分和低分采样。另完整报告全零/全满分/其他同分/有方差组数、每组正确个数、删失个数、token多样性和canonical重编码差异；不能只报告best-of-8掩盖单次能力。所有采样得分是训练信号，不是新模型泛化得分。

通过也**不自动训练**：原GT可见支持不保证新低分采样都是语义错误；需逐图核实新正负对应，另登记新matched SFT与在线策略优化单变化、相同起点/回放、独立新验证/保持与原主任务门槛。失败则停止本轮采样设置，不加组数、温度、seed或扫参数凑通过。原SFT/DPO512验证失败结论不回写，不能把这32题采样收益写入简历。
