# 区域文字监督SFT：首阶段匹配对照

2026-10-19，用户授权“执行下一步实验”。本协议在新模型预测之前固定；数据仅来自既有TextVQA train_all图及官方TextOCR训练标注。旧科学源、模型、预测和门槛不改。

假设：明确文字区域与官方转写提供的细粒度监督，比相同训练图上的普通继续SFT更能改善原图TextVQA及罕见监督答案，同时保留人工yes/no能力。研究新增监督粒度，不称原创loss。

两组从同一原始FP32 SFT42语言q/v LoRA出发，1843200可训练参数；BF16底座、FP32 LoRA/冻结输出头/CE，关闭全局AMP和TF32，视觉冻结、dropout0，显式原始greedy解码repetition_penalty1，max_new_tokens32。均建立新同策略初始基线，不拼接旧数值路径结果。

从既有训练白名单挑1600张图，每图至少两条不同且规范化target获8/10以上原答案支持的TextVQA QA与一个有效TextOCR区域。选择仅依据固定hash、官方标注、可见性几何和已声明训练划分，不用任何模型错误或保留集答案。两组共享同图第一条QA；控制辅助为第二条原QA，候选辅助为区域转写QA。各3200唯一QA、每图2次曝光；每更新8共同+8辅助，按同一图序组成4个4QA微批，200更新/effective16。新增区域标注/输出长度/实际tokens单列，等QA不冒称等信息/等计算。

区域从points求原像素外接框，再转换明确声明的0—1000坐标；训练输入始终为完整原图。过滤`.`/空/非可打印/超40字符、非法坐标、倾斜超过15度、实际1024预算resize后宽不足16或高不足12像素、面积超过半图、含其他词中心的框；图像尺寸与源注释不一致则排除。内部dev/final与人工图像file/pixel身份排除；同源公开JSON中非白名单记录不参与准入或选样。固定原图预览只作局部监督核验，不称全量人审。

固定AdamW LR2e-5、warmup20后线性衰减、weight_decay0、clip1，均使用逐QA平均assistant CE，不加首词重权、梯度投影或偏好/RL。复用既有FP32 loss/元数据/保存恢复实现，25步保存完整Adam/RNG/游标，首步即存；每臂累计训练active上限2700秒，异常非有限/零梯度/输入截断则停止自身分支，不中止其他任务。

训练前在固定hash的64条区域训练QA上记录新初始模型输出，分别报告原字符串匹配与EvalAI规范化匹配。只有规范化错题至少4/64才放行训练，避免将单纯大小写/标点差异当视觉纠错空间；不据输出换题、扩采样或修改阈值。这只是训练信号准入，不是泛化收益。首阶段筛选使用既有内部Text512和Human512，明确它们已反复曝光，只作探索。Text rare1—5/frequent>20频次沿用原32985 QA规范化target，不能换成新OCR词频。

候选需相对新鲜初始和新鲜控制均满足：Text整体及rare点值至少+0.5pp；整体图像簇95%配对区间下界>0；frequent及Human总体/yes/no点保护不低于−0.5pp。6000次固定seed20261019整簇bootstrap，Human按既有连通组件聚类。全部升降和切片区间公开；单seed/已曝光筛选不称正式稳定能力提升。旧人工QA+1pp、pair+2pp分支的失败不追改，本项为独立OCR监督研究。

失败停止，不扩epoch、不扫参、不挑checkpoint、不自动扩种。只有筛选全过才进入零训练的条件确认：Text内部dev扣除全部screen图像后的剩余题与原Human确认折，按图像隔离，不仅扣题ID；这些数据在历史研究可能已曝光，必须据实标注，不把full-dev包含筛选题的重评当独立确认。不进入旧正式TextVQA/DocVQA/MMStar调参。确认规则同筛选；无自动长训/简历提分。

训练时间以实际正式步速报告；预算上限不是ETA。已有GPU任务不抢占，沿用三次15秒空闲采样、至少40GiB及共享UUID锁。源/配置/数据/图像与CPU输入在GPU前锁定，端口变化后按断点恢复。
