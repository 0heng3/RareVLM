# 困难视觉监督的200步SFT筛选 v1

2026-10-18。针对先前均匀人工SFT主要移动yes/no倾向、没有可靠额外区分力的问题，检验训练池内可由图像核验的困难监督是否比同预算均匀监督更有效。旧完整SFT和Final@1负结果保持。

## 数据与复核

从原3893条人工训练问答按固定image_id hash分为train3148QA/1477图、screen368QA/167图、confirm377QA/190图。旧模型曾在本数据池训练过，但本轮均从原始SFT42起点开始，三折在本轮continuation中图像不重叠；不称全项目或预训练未见。旧474题不用于训练或称作新盲测。

先仅生成train与screen初始预测，不生成confirm。困难项必须为原始SFT42实际greedy生成有效yes/no但判错的训练题；格式错误不纳入本困难定义。按每类32条固定hash抽取首批64条，展示图隐藏原标签/模型答案，由助手看图复核；保留原人类标签，图像不清、不可从图像判断、答案与原标签冲突均不进入困难池。若不足，可继续获取训练池剩余候选的图像证据，记录全体复核结果，不把选择后的通过率当总体质量估计。

困难池需每类至少12题、至少10个图像。其依据是每类200次困难曝光下单题不超过约17次，避免极少案例反复记忆；不足不启动训练。复核是助手验证图像依据，不能声称新增专家人工标注。只对训练池做选样，screen/confirm标签与分母不改。

## 两分支固定设置

每分支3200次QA曝光/200更新，不是3200个独立训练案例。共同1600条高一致性TextVQA回放：按原完整32985监督目标频次，rare1–5取400、mid6–20取400、frequent>20取800，固定hash取图像不重复项。两分支Text完全相同。

人工曝光各1600，yes/no各800，标签槽位顺序相同。候选中每类200次来自已核验困难池、600次来自原模型正确的容易池；控制每类800次均匀来自同一合格池（容易项+已核验困难项）。训练前固定所有曝光，困难重复项保留原question_id来源和独立exposure ID，不算新独立数据。两分支使用同seed42位置排列。

同原raw-FP32 uniform SFT42 adapter、BF16底座/FP32 LoRA、无全局AMP、显式FP32逐QA CE、语言q/v rank8 alpha16、1843200参数、dropout0、TF32关闭、nonreentrant checkpointing；micro4/effective16、视觉上限1024、序列上限2048不截断。AdamW peak LR2e-5、weight_decay0、clip1、20步warmup后在200步预算内线性衰减。Final@200是唯一训练候选，非看dev挑checkpoint。

该200步是本轮完整预注册小预算，不自动改调度延长训练。后续若需新增训练预算，另立协议；优先独立确认和种子复核，不为满epoch重启长跑。复用已有FP32训练、损失和断点实现；单分支训练上限45分钟，超限只停止本协议自己的训练进程并保留断点，不操作其他任务。

## 筛选与确认

screen368题用与基线相同batch4、1024预算、greedy32及原yes/no首词计分。Text screen固定128个原始完整四题批次共512题，按训练无关hash选批并保持批内分组；初始预测从相同raw-FP32基线推导复用，记录原文件SHA，不重复生成。

筛选放行到确认评测须同时满足：人工对初始及均匀控制均>=+1pp，图像簇95%配对区间下界>0；相对每个比较对象至少净纠正6题；相对初始yes/no各类点值不低于−.5pp；Text screen整体及原始父模型rare/frequent切片点值不低于−.5pp。频次切片作为父模型完整32985监督曝光的纵向保护，另保存本pilot真实曝光，不将其误称pilot频次。

4000次image-cluster bootstrap、seed20261018，全部纠正/新错保存。筛选是开发证据，不叫独立确认；未过或未定不评测confirm、不加训练预算。

若筛选通过，冻结权重再生成confirm377题的初始/候选/控制预测，采用相同>=+1pp和正区间要求；再做完整Text1617的−.5pp区间非劣及rare/frequent点保护。确认仅增加评测，不新增训练。通过也只称单continuation seed42小预算结果，不自动扩长、写简历或宣称三种子稳定。

所有GPU使用已有共享UUID锁和连续空闲准入，不终止其他作业。数据准备、训练、筛选、条件确认分别报告进度/耗时，早期信号不保证成功。
