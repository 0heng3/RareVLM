# Qwen-VL QLoRA SFT：实际执行结果

执行日期：2026-10-09。完整流水线状态为 `complete`；这是独立于冻结 CLIP 长尾研究的生成式工程模块。

## 已执行的链路

**图像与问题 → Qwen2.5-VL-3B-Instruct → 语言层 QLoRA SFT → 生成短答案 → 配对评测 → 本地推理验证**。

- TextVQA：1,024 张训练图、128 张内部验证图、256 张最终评测图，每张图选一个问题；图像 ID 与解码像素哈希互斥。
- 来源池：官方 train 的前 4,000 条问题与官方 validation 的前 1,000 条问题，固定 revision 和哈希选择。6 条没有可用归一化答案的注释在选样前排除。
- 4 张 V100 16GB，seed0，固定一轮，effective batch16，64 次更新/rank，跳过更新为0。内部验证 token NLL 为 **0.6465**，仅作诊断。
- 训练 **1,843,200** 个语言 q/v LoRA 参数，占含 adapter 总参数 **3,756,466,176** 的 **0.0491%**。视觉编码器、连接器与语言底座冻结。
- 语言线性权重使用 NF4/double quantization，计算与视觉编码器使用 FP32。基线与微调模型的量化、图像预算、提示词和 greedy generation 设置一致。
- 仅助手回答及结束 token 参与损失；参考答案未进入生成输入。固定最终 epoch，不按最终评测结果选择参数或 checkpoint。

设置、失败修复和复现命令见 [协议](VLM_SFT.md)，官方岗位依据见 [路线映射](JOB_ROUTE.md)。

## 配对生成评测

分数单位为%；共识分采用声明的 compact normalization，不是完整官方 TextVQA benchmark 分数。

| 条件 | 归一化 VQA 共识分 | 至少匹配一个人类答案 |
| --- | ---: | ---: |
| Pretrained instruct，NF4 / FP32 | 68.55 | 70.70 |
| 同配置 QLoRA SFT，固定一轮 | 71.52 | 75.39 |
| 配对变化，pp | +2.97 | +4.69 |

256 张图中：**21 张共识分提高、10 张下降、225 张不变**。2,000 次条件配对图像 bootstrap 的 95% 区间为 **[-0.20, 6.25] pp**，包含零。因此该子集上的正向点估计不能写成已证明稳定的质量提升。区间也不包含训练种子或跨数据集不确定性。

早期归档 FP16 基座参考分为 **71.41%**，不纳入 NF4 配对增益计算。本轮结果没有建立优于 FP16 基座的证据。答案格式与词汇变化也影响分数，不能将其直接归因为 OCR 感知能力提升。
