# 多词回放：扩覆盖还是重加权

2026-10-21事前登记。上一高lr研究已完成且联合失败，原Final/门槛/标签不改、不加步。高lr覆盖128训练满分56，验证93.085938%，对初始−.136719pp，CI跨0；4题升分+3.7抵不过5题下降−4.4。三例完整名称缩短有原图支持，蓝W→U明确；ndaine/andaine左端遮挡语义不确定，原评分保留。高lr重复32未参与监督96题有17满分，不称完全不迁移。

训练曝光中946/1024是单词答案（92.3828%），多词78；验证单/多各256。长度分布与三例缩短是关联证据，不是因果结论。原64保持32单词/32多词均93.75，覆盖不足以代表整个验证域。下一项只检验多词回放的不同信息覆盖与已有样本权重，非新RL/架构/加训旧Final。

两组都从原uniform SFT42重新开始，同128已审困难题、每题4次，64更新/512hard+512replay，峰值lr2e−4/warmup8/linear/AdamW wd0/clip1，FP32语言qv1843200、BF16底座视觉冻结、冻结FP32头/dropout0，assistant内容+真实EOS/每QA均值不变。所有困难slot与原coverage128逐位相同。

* `expanded240`唯一候选：保留原50道多词回放，固定SHA从原矿池training fold初始满分的其余194多词中取190；再按频次桶选原单词回放slot一对一替换。共512不同回放=240多词+272单词，均权重1、每题1次，频次桶总计与原512相同。目标多词数240事前固定，不能用验证答案挑新训练题。
* `weighted50`新强控制：原512不同回放全部保留（50多词+462单词），每题1次；按`(frequency_slice,stratum)`设权重`w_cell = expanded_count_cell/original_count_cell`。各频次桶/单多词的总监督权重与候选完全匹配，总回放权重512、多词权重240。它没有新增190道不同多词信息；没有把加权曝光冒充真实多词样本或增加QA调用。

两组每步loss为`(Σ8hard CE + Σ8replay w_i CE)/16`；CE本身是每题正文+EOS token均值。硬题权重1；控制每步总权重可能不同，只保证完整调度累计分层权重匹配，梯度方差/图片/长度/视觉token/计算成本仍可不同，不作纯抽象样本量或等FLOPs因果。候选实际多词曝光28hard+240replay=268/1024（26.1719%，没有达到50%）；控制实际多词仍78、但累计loss权重268。选择240而非256是因为训练fold仅244初始满分多词可用，并保留4题余量；不从512验证拿题、不重复样本来伪造不同覆盖。首次/末次逐题CE、权重、梯度、LR与耗时追加保存。

复用已有640项真实CPU合同，只编码新190项，共830唯一训练输入；旧初始预测/实际完整batch4训练468背景/仅128计分、验证512和保持64原样复制，0新基线/矿池/旧编码调用。候选与控制Final各1044实际生成，704评分QA。验证独立于这轮新增训练，但属于原SFT train白名单且已用于内部研究观察，绝不称原SFT未见盲测。旧高lr plain128是固定历史参考、不可回调。
