# 完整词任务匹配回放：先验证遗忘，再作一次固定预算SFT对照

2026-10-24，新诊断及训练输出前登记。上一大小写对照已完整失败：canonical128训练69/128，新词117/128，初始121/128；raw训练52/128，新词118/128。观察到Hawick、AGNEW、Westmalle等原本正确词发生字母替换，只能提出任务内遗忘假设，不能据此断言唯一根因或视觉编码器缺陷。

## 问题与先行诊断

原384条目录由128纠错词和256整图VQA回放组成，没有完整词转写的正确回放。假设：任务匹配的正确转写监督可能比部分整图回放更能约束读词能力的漂移。此轮只考察回放分布，不增加LoRA容量、不引入DPO/KL/RL、不调学习率或增加步数。

只从原ROI training_pool2048取候选，要求原始模型literal_exact正确且自然EOS、词长>=5、原裁剪宽>=60/高>=24；与128纠错词、新128/旧256验证按原图、decoded pixel和canonical词隔离。按固定SHA取192候选，展示实际词图及官方标签，助手作完整性/拼写/可读性审核，首128支持项冻结；审核不看上轮Final输出。筛选用原模型正确性明确记作训练回放的构造条件，不冒称完全prediction-free采样、专家真值或独立能力评测。所有原图曾进原SFT train_all。

复用原始模型对这128词的同输入预测（128/128正确），只新增上轮固定canonical Final128的128次生成。**至少丢失4/128（3.125pp）才准入训练**，不是统计显著性或能力门槛。少于4则停止该分支，不强行训练或调整门槛。保存所有预测，无挑选错误重新补数据。该集将进入候选训练，只是任务内保持诊断，不能作为泛化收益。

## 唯一训练候选与既有匹配控制

候选从原uniform42 SFT5d8 fresh加载，绝不从负Final接训。直接复用已验证的`run_literal_case_sft_v1.train/evaluate`循环，在独立ROOT绑定新数据；不改冻结源。控制为已完成canonical_case128。共同语言q/v144、1,843,200 FP32可训练参数，BF16底座/冻结FP32 head、dropout0、TF32off、冻结视觉、1024视觉上限；seed42、128更新、micro4/effective16、LR2e-4、warm8/全128cosine、wd0/clip1；Final128固定，step32只生成128训练词作拟合诊断。

保留旧128更新的全部hard微批和第一个native微批，第二个native微批的128个不同QA按固定顺序一对一换成128审核正确词。每步`native4/hard4/literal_replay4/hard4`；128纠错词各8次、128原native各4次、128新词回放各4次，共2048QA。原控制是`native4/hard4/native4/hard4`，256native各4次。候选384不同QA，保留的256条训练CPU input/labels与原控制完全一致。完整词纠错与回放的训练target均NFKC/casefold/strip，native标签和所有官方评测target不变。

目标仍是逐QA的assistant token平均CE：`L=(sum CE_hard8 + sum CE_native4 + sum CE_literal4)/16`，包含真实EOS、忽略prompt/padding。两条件等更新、等QA、同硬题次数；回放图像、问题、标签token长度和padding改变，因此不称等token/FLOPs或严格单一模态因素归因。原控制不重训、不重复已通过全局mask/加载诊断；实际新词CPU编码、全部训练输入SHA及有限梯度检查沿用旧路径，完整Adam/RNG/trace-offset/UUID恢复。

## 评估与判定

初始/旧控制的原五队列完整预测只读复用。新Final生成hard128、新词验证128、旧词验证256、native512、保持64，另对128训练回放词生成保持诊断；step32只hard128。新旧验证数据不改，不用已观察的退步样本补训练。回放正确率上升只说明保持，不是能力提升。

保留上一轮门槛：hard>=96/128仅可学性；新128词验证对初始>=+3pp且6000次配对图像簇95%CI下界>0，native512对初始>=+.5pp且下界>0；native单/多词和rare1–5各点差>=-.5pp、保持64>=-.5pp、旧256词>=-.5pp。另要求新词验证对旧canonical控制>=+.5pp且CI下界>0，才称该回放变化有外推优势；不能只胜过退步控制。原native强回放/1617与长尾主目标不被新任务替换。

只有全部初筛条件通过才对新候选补原1617迁移，分别与同帧初始、原强q/v回放比较，不因候选过初筛就宣称项目完成。失败不追加步数、种子、β或RL方法。单seed内部研究，区间条件于固定模型，不含seed稳定性；反复使用内部dev不是盲测。

共享队列零compute、>=40GiB、利用率<10%、三次15秒空闲、UUID锁，不抢占其他任务。诊断上限300秒；训练1800秒、主评测1500秒、附加回放评测300秒，allocated<=65GiB。学习页连接真实词图、公式、现有源码及保存回答；CV/论文/Agent/CI不改，不push。
