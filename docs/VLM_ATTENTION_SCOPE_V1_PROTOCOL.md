# 注意力LoRA可训练范围：匹配CE短预算实验 v1

2026-10-19，用户授权继续修复至可执行新实验。本轮将已修复的数据准入与运行元数据接入真实训练，不重复旧加载/mask/断点全套审查。

## 问题与单一变化

已完成SFT对可靠困难视觉判断的纠错不足，跨图排序没有带来超过CE的能力收益。原始梯度和Adam位移检查表明不能直接统一放大首答权重，也不能断言数据或优化器是唯一主因。当前仅训练语言q/v的适配范围尚未做本轮数据上的匹配容量对照。

本轮检验：在同一已修复训练池和普通CE下，允许k/o LoRA参与更新，能否带来超过q/v强控制的独立生成纠错。容量不足只是待检假设，不预先承诺提分；该对照不是原创损失或RL。

初始化：从原始FP32 SFT42 q/v checkpoint原值出发，新增k/o的A按固定CPU seed42 Kaiming-uniform等价分布初始化，B严格全零。两组共享同一完整q/k/v/o图与全部3,686,400个LoRA参数；控制冻结新增k/o，仅1,843,200参数更新，候选全部更新。q/v旧值不变，rank8/alpha16/dropout0相同；新增零输出保证共同函数起点。视觉tower、merger、MLP、embedding和lm_head冻结。

新入口`vlm_runtime_metadata_v1.model.load`保留FP32 LoRA并同步dropout配置；普通CE先assistant token均值、再按QA平均，保持原3token语义，不增加rank项或改变格式权重。上游参考为已归档Qwen兼容训练入口的q/k/v/o目标；该源码属于含2.5支持的当前Qwen3-VL仓库固定提交，不冒称原始2.5官方训练配方。

## 数据和预算

- 新`vlm_semantic_admission_v2`593互补训练对/1186QA，排除7对已知不确定监督。1155QA仍仅官方高共识，31QA有额外审核支持，不宣称全量视觉正确。
- 共用原1600唯一Text回放，保持原Text顺序。每更新8Text+4互补对/8human；200更新/3200QA曝光=1600Text+800pair。593对先完整随机遍历，再次洗牌取207对；两臂顺序逐QA相同。独立训练QA总数2786。
- seed42单次延续，LR2e-5，20warmup/200步衰减，micro4/effective16，AdamW decay0、clip1，BF16底座/FP32 LoRA/FP32 CE，无全局AMP/TF32，非重入gradient checkpointing，visual eval。
- 训练视觉token上限1024、序列2048，超限拒绝、不截断。新增参数和实际耗时/显存单列，不能称等参数或免费提升。
- 每臂累计训练45分钟上限；不扩epoch、扫LR/rank或挑checkpoint。共享GPU三次15秒/零compute/40GiB/低利用率/UUID锁，不终止已有任务。

## 新增改动的验证和训练放行

新增CPU检查只验证q/v原值保留、新k/o零输出、真实PEFT前向等价及两种requires_grad范围；复用已验证的训练循环、FP32 loader、CE和断点。

首个GPU阶段对共同扩展初始化完整生成human screen512和Text screen512，逐题核对已有原始q/v基线的问图身份、实际输入/视觉token和答案。若新增零输出图与原始基线预测不一致，停止进入训练并保留结果，不据部分结果放行。新鲜共同基线的完整LoRA哈希在训练前固定，两臂从同一文件加载。

首正式更新即验证候选新增k/o B收到有限非零梯度，A初始零梯度合法；控制k/o不应有梯度，Final仍须保持新增k/o原值。没有丢弃的预检训练步或额外reference forward。首步记录是执行证据，不是能力提升。

## 筛选、确认与停止

复用原图像隔离human screen256对/512QA（222组件）与Text512完整批次；已多次曝光的screen明确为探索筛选，不称盲测。Final@200候选对共同初始和新q/v控制均需：

1. human QA≥+1pp、成对≥+2pp，各净纠正≥6且组件簇95%区间下界>0。
2. yes/no与Text整体、rare1–5、frequent>20点值下降均不超过.5pp；保持比较同时对初始和q/v控制。

完整报告纠正/新错、两类、文本频次切片、实际资源。失败停止，不按screen调参，不写CV新收益。

只有上述全部通过，自动以冻结Final对原保留human confirm256对/512QA和Text全1617做0更新确认，初始/qv/qkvo三模型同口径；确认沿用主收益及保护，Text总体95%区间下界>−.5pp。confirm数据只在放行后解析与评测，旧结果/标签/分母不改。此后若要正式成果仍需独立种子0/200等复核，本轮不自动扩训练。

所有配置、新源、原依赖、训练/筛选清单、initializer权重及包版本在新预测前冻结。新模型注入是本轮变化，因此完整共同基线与首步新增模块证据是必要验证；不重新跑已过旧32QA拟合或旧全量审查。
