从已审128题的16个实际(error_type,frequency_slice,stratum)层，各按固定SHA取1题。选择不读Final分数，16题都来自已用于训练和诊断的数据，不是盲测。两组原uniform SFT42同一FP32 q/v LoRA 1843200参数、BF16底座/视觉冻结、冻结FP32输出头、dropout0、相同16题/图像/顺序，assistant正文与真实模板EOS，不监督EOS后换行。每步4题，循环16题16遍，共64更新/256曝光，普通每QA平均CE，无回放。仅峰值学习率2e−5与2e−4不同，warmup8步、线性衰减、AdamW weight_decay0/clip1。该诊断同时不同于旧128题含回放训练，不能拿旧Final当本轮低学习率控制。

在固定0/16/32/64步，同一16题固定batch4分别保存teacher-forced每token logp/rank/竞争token/margin、正文与EOS CE，以及实际greedy生成IDs/EOS/官方VQA分。每组0与64步另跑原64题保持，均新鲜同卡同batch4初始对照；不引用旧不同batch数值作新初始。共每组192条生成、64题teacher-forced诊断前向、256题训练曝光。初始与Final逐题正文CE才是同帧配对，在线训练loss另列。

单臂拟合门槛：Final满分≥13/16且较本臂初始净增≥10，配对正文CE降幅≥50%。只有高学习率通过、低学习率未通过且高组Final至少多4满分，才记为本诊断支持学习率/更新尺度瓶颈；仍不能证明新数据泛化。两组均过仅说明当前可训练路径可拟合该16题；均不过则不能因loss下降宣称修复，优先根据token证据检查首错误位置/视觉条件与适配容量。保持下降照实报告，无回放诊断的遗忘不等于旧协议遗忘。
