# 整图监督替换裁词回放：完整结果

本轮两臂各32更新，内部960题和完整1617题全部评测成功，新增64正式更新、5,154次生成。原控制器在汇总处导错`paired`函数；锁外恢复只在内存中修正导入，复用原统计和门槛。42个受保护的源码、锁、权重、预测、旧分析和日志文件保持原字节，恢复为0GPU/0训练/0新生成。

## 问题与对照

原128条审核支持的原生纠错各曝光两次，128原生回放保持；仅将128条IIIT裁词正监督替换为固定128条ST-VQA整图正监督。384不同QA、512次chosen曝光/角色，视觉30层qkv的60个FP32 LoRA因子共1,843,200参数，语言与基座冻结；共同起点、seed42、32更新、lr2e-4、beta0.1及损失口径保持。

SFT优化逐QA的assistant token平均CE（含真实EOS）；另一臂增加基于序列sum-logP的reference DPO，仍使用原128条审核偏好，新ST-VQA来源不生成负例。数据来源、问题与答案组成共同改变，不能作纯分辨率因果归因。历史CE/DPO和起点预测按SHA复用，不当新独立重复。

## 真实得失与机制边界

新SFT对起点29题升、13题降、净+13.4个VQA分数单位；新DPO对新SFT11题升、22题降、净−11.7。SFT改善的29题中17题加入DPO后得分下降。原128训练纠错中满分题SFT37、DPO38，拟合增加不等于完整任务泛化。

事后四组交互`(新DPO−新SFT)−(旧DPO−旧CE)`为−1.051330pp，探索95%区间[−1.884737,−0.247368]。这支持本配置下数据策略与偏好损失效果不同，不证明唯一数据噪声、梯度冲突、容量或架构原因。区间按1024物理图像整簇6000次bootstrap，只涵盖固定模型条件，不包含种子方差、全历史多重选择或预训练重叠。

## 停止与下一验证

关闭本固定配置扩步、seed、DPO权重/LR和mix扫描，不为算法关键词直接启动PPO/GRPO。另行预注册四个固定Final在256张未训练来源保持图上的评测，1024新生成+1024 GT前向、0更新；它只解释来源内泛化与损失取舍，不替代原native强基线、三seed和外部能力验收。
