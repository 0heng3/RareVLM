# 局部教师数据准入 v1

本轮是训练数据可用性检查，0 optimizer updates，不是能力评测或蒸馏训练。此前7条教师可用性已完成，不重跑、不计入本池。原后层/rank路线继续关闭。

## 事前限定

- 只复用官方训练问答、TextOCR train 的独立文字框和两个已完成库存：native_ocr revision2、native_smalltext 的104条小字候选。所有源图已在原始SFT的train_all出现，不称未见训练数据。
- 重新排除当前384训练QA、全部关联评测、原dev/final以及此前7条的图像ID与解码像素身份。每图一个问题；候选每个答案最多2张图。
- 保留原问题和GT；至少8/10共识、单词字面一致、唯一OCR标注。裁框取标注外接框向外取整并加2个原生像素；若边长不足处理器要求的28像素，则在原图上居中向外扩至28像素并受图边界约束。对最终扩框排除其他文字中心；裁图不插值。区域只给训练教师使用，不用于实际评测按答案裁图。
- 最多512张不同图。排序固定：旧初始模型错误候选优先，然后小字，然后其余；组内按文字高度、固定SHA。旧预测只用于训练候选排序；新整图/局部均以当前共同起点重新计算。没有结果后补池。
- 主教师唯一为共同初始checkpoint，不在两个教师中择优。BF16视觉/FP32语言及LoRA、dropout0/TF32off，原1024视觉预算、greedy32、batch1。
- 两个静态分片经共享GPU空卡队列运行，各最多1200秒/65GiB；不抢占已有任务。每候选2次生成、2次GT前缀前向，最多1024次生成+1024次前向。

## 冻结准入规则

逐条要求：局部自由生成严格字面匹配并自然EOS；GT前缀正文全argmax正确；正文NLL≤0.2、EOS NLL≤0.2；整图正文NLL减局部正文NLL≥0.05。先按固定候选顺序取前128条，每答案最多2条，其他候选全部保留拒绝原因。

足量门槛：128张不同图、至少96个不同答案，所选至少32条整图严格错误→局部严格正确，所选平均正文NLL下降≥0.2。正确但不够自信的样本单列，不能称128条真实纠错。门槛失败就停止，不放宽阈值、不自动扩池/训练。

## 教师信息审查与未来对照

对齐同一GT正文token，计算 KL(p_crop || p_full)、教师非GT概率、CE输出logit梯度 g_CE=p_full−onehot(y)、KD梯度 g_KD=p_full−p_crop 的余弦和相对差；EOS单列。这是输出层梯度诊断，不冒充参数梯度或泛化证据。

未来拟议 CE(full)+KL(crop teacher||full student) 必须对照 **2×CE(full)**（相同监督权重、相同数据与步数），另保留历史强控制。若教师趋近GT独热，CE+KL近似2CE；不能把loss放大当作蒸馏信息增益。本轮只报告这个诊断，不自动准入训练。

任何后续训练还须另行固定算法实现、预算及完整1617/保持集对照。整图推理、相对共同起点及匹配强控制至少+0.5pp且图像簇CI下界正、长尾/保持保护，以及后续三seed/外部确认要求不变。当前目标未完成。
