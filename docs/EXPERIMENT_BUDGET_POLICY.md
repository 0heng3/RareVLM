# RareVLM新探索的预算与放行规则

依据用户2026-10-18的成本与成功把握要求。本规则约束后续RareVLM新探索；不追改历史冻结协议，不影响其他项目或用户明确指定的完整复现。

训练可执行、梯度非零、loss下降、权重保存和多人标签一致性，都不是数小时训练的充分理由。长任务的依据应为可靠、未参与该训练的样本上的能力改善、匹配控制及保持证据。独立历史样本不足时不承诺80%/90%成功率。

## 分阶段执行

1. **立项证据。** 写清强基线错在哪里、训练池是否有同能力的可靠纠错信号、所需净纠错数量和成本。高一致性不替代图像可验证性；不因方法热门或GPU空闲直接长训。
2. **小预算筛选。** 首阶段每分支默认约30–45分钟或事先冻结的小更新上限，使用真实数据、独立图像筛选集、原生成计分及匹配控制。阈值、停止/继续规则在看结果前固定。训练拟合和小样本正控制不算能力证据。
3. **逐级加预算。** 主指标有明确净收益、优于强基线/匹配控制，且保持任务可接受才进入中预算，再决定是否完整训练。信号不足默认不解锁长任务，可承认未定；不能据无早期收益判所有算法必败。短阶段需覆盖预热后的有效优化；扩展从已冻结前缀断点延续，换调度则另立协议。
4. **独立确认与复现。** 筛选/校准不冒充未见确认；已反复用过的dev披露曝光。冻结候选/选点后再确认、扩种和正式评测。短预算本身若已有可靠确认，可作为相应预算下的成果，不为完整外观强迫跑满epoch。

## 长任务的必要放行证据

- 一页协议包含问题、变化因素、强基线、数据/计算预算、最小主收益、保持标准及失败停止规则，不按dev扫LR/epoch。
- 筛选集上的纠正和新错、yes/no等相关类别、保持任务完整报告；不能只改善一类而损坏另一类，也不能用loss/reward/margin上涨代替得分。
- 训练监督覆盖真实可学习错误；需要时只在训练池内核验困难样本，禁止dev错题回填训练。
- 已完成加载/mask/断点证据复用；完全相同model/data/order/seed/数值/预算的初始预测和控制可复用并披露相关性，不当新独立重复。条件不符不得拼接。
- 有实测步速、token/source占比和恢复断点；显存余量不自动表示增batch提速，不让新增封装/审查代替有效性研究。

若延续当前人工yes/no任务，原+1pp对同口径初始/控制及Text保持要求不降低；旧474题已用于诊断，不重新称盲测。历史200步回放是一个案例，不是已校准的成功率。

下一候选先检验“训练池内、图像可核验、困难正负平衡的监督是否真正纠错”。证据不足时不自动启动新数小时训练。
