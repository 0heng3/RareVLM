若主信号通过，下一阶段只允许另登记足量、可靠训练候选的局部教师/整图学生对照；本程序不训练，不把7条当有泛化意义的训练集，不自动扩池/正式集/seed。若仅正文信号存在，未来需保留GT结束符监督、另测正文蒸馏，不能直接用全词表全序列KL。信号不足停止本配置，不调整crop/提示/阈值以求通过。
