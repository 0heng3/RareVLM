# 真实错误监督：同数据SFT与CE+DPO短对照 v1

2026-10-20、错误挖掘生成尚在进行时预登记。执行依赖`VLM_ERROR_SUPERVISION_MINING_V1_PROTOCOL.md`完成及可见证据准入；本文件不是已经训练或提升的声明。旧EOS专项32对门槛与5对不足的结论不变，新研究覆盖实际错误的不同文本类型。

## 研究假设与数据

之前增加长答案比例主要重复原已会的题；真实原始SFT误答构成的监督，可能比容易回放带来更多有效学习。DPO是否比同数据完整CE更好，另看实际生成，不由偏好loss或训练题记忆断言。

训练仅使用已固定的1024训练池：算法候选按预定SHA顺序，至多审查前64对，取其中最先32对可见证据明确支持chosen且rejected确实较差的问答。含糊、不可辨认、答案不唯一等排除并记录，不按候选模型结果挑选；不足32对不训练。其余训练池中初始实际得满分的题，按固定SHA取128单词+128多词共256题作共同回放。32个错误图、256回放图、512验证图及旧64保持图完全分离；源于初始SFT训练白名单，不称初始未见。

512验证题在新生成之前已固定，完整复用矿工实际初始预测，并保留原分片内batch4的分组/顺序，使Final与初始的输入批次形状相同。它不用于挖训练对。旧64保持来自scope-balanced v2原EVAL，未被本轮训练使用。32训练错误与64保持在reference阶段重新实际生成固定起点，和512缓存基线分别记录成本。

## 两臂与训练预算

- 起点均原始uniform SFT42，不续训退化Final。原BF16底座、FP32语言q/v LoRA1843200及冻结输出头；视觉冻结，dropout0。
- 每臂32更新、512个chosen曝光；每步8真实错误+8共同回放，micro4。32错误各8次、256回放各1次，使用独立Random(42/43)固定洗牌，两个角色共享完全相同输入顺序。
- LR2e-5、warmup4、AdamW/weight_decay0、grad clip1、1024视觉上限、max sequence2048、Final固定32。沿用已验证训练循环与FP32保存/恢复，首步和每8步checkpoint；每臂active900秒上限，不追加步数或扫参。
- `sft`: 每问题完整assistant-token平均CE；`dpo_sft`: 相同CE + beta=.1、lambda=1的DPO，仅32错误题有偏好项。DPO采用chosen/rejected完整序列log-prob求和与冻结同起点reference，不按序列长度重新归一化；chosen CE仍逐题平均。两臂均计算相同负序列，SFT的DPO权重0，保持forward形状一致；每臂256负前向，reference另计。
- reference按实际padded微批冻结且无梯度，实际padding与actor一致；初始化relative margin及首步FP32保存沿用已验证检查。无需重复旧全量精度/加载诊断。

## 实际生成与固定判定

Final每臂32训练错误+512独立适配验证+64保持，共608生成；raw greedy32、batch4、原图1024，无GT输入，原TextVQA评分。完整报告得分、纠错/破坏、单词/多词、频次代理和文本关系；训练纠错不算迁移提升。

两候选各对initial的512验证比较为预定主比较：VQA至少+.5pp且图像簇95%双侧bootstrap下界>0（两次正向检验按alpha=.05/2；6000次、seed20261020）。此外单词与多词点值各>=−.5pp、64保持点值>=−.5pp、32训练题满分净纠正>=8，全部满足才有资格另行原主Text/Human筛选。保护点值不是正式非劣证明；该小样本通过也不替代原主任务/rare/frequent/跨任务门槛。

DPO相对同数据SFT的+.5pp和正95%区间仅为预先声明的次要探索条件，不纳入上述两主比较的家族保证，不据此写三seed或正式泛化收益。若SFT有效而DPO无额外优势，应优先简单SFT；两个都未过就停止此研究，不扩步/seed/主测，不换RL名继续。正式benchmark不用于回调训练数据、预算或checkpoint。
