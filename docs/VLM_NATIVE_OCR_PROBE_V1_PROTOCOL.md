本轮先检验新的可靠监督来源，而非直接加一项损失。原SFT train_all 32985QA中，排当前640训练/context/seen/保持及原dev/final同图像与解码像素，筛原问题含文字/名称/品牌提示、非颜色/价格/计数/时间问答，至少8/10原始答案规范化一致。预测前按固定SHA选择唯一图像、目标最多8次；候选目标必须在官方TextOCR训练标注中唯一匹配，水平角≤15度、面积≤半图、1024预算resize下宽≥24/高≥16像素，原图/问题/标签全不变。

初版prediction-free盘点1458图/1221规范化target（rare1114/mid216/frequent128）。发现VQA规范化会删除冠词或合并标点，不能作为完整文字证据：如`a conversation`只对应OCR`conversation`。原INVENTORY/CANDIDATE_ROWS不改；revision2在任何新模型输出前排除原target多词、NFKC/casefold后保留内部字词的字面不一致，以及目标框含其他OCR词中心的条目。记录全部排除原因，不改原GT、原分母或历史分数。若剩余不足1024，准备停止，不降低过滤条件。

实际CPU编码全部新推理前缀，记录input_ids SHA/原始grid/长度，检查OCR证据的resize几何与实际processor一致。框只用于选择和网页展示，模型仍只接收原图+原始问题+既有短答提示，没有框、OCR答案或裁剪输入；高共识+独立OCR证据不称专家逐图重标注。

固定评估三模型：原始uniform SFT42；旧q/v加强回放Final（β28.9777，旧1617最高点值87.767471）；最新固定q/v的MLP-KL Final（β100，旧迁移87.452072）。不挑新checkpoint、调提示或解码。全部BF16底座/精确FP32 LoRA与独立冻结FP32 head、TF32off、greedy32/repetition1/batch4。按全cohort的固定4题批次交替分两卡，各模型相同帧；末批不足4合法。每角色2分片，6任务动态接续共享空闲GPU，保存实际completion_ids/EOS/输入hash，加载前后adapter hash不变。
