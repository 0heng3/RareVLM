# 等视觉 token 的区域信息分配：区域优于弱对照，仍落后单整图

四条件内部 dev 已完成，共 6,468 条预测、0 次新训练。单整图最高 84.886%，文字区域方案 79.035%；后者相对随机区域 +2.072 pp、相对双整图 +1.664 pp，却相对单整图 −5.850 pp。`gate=true` 仅表示超过预设双视图对照筛选，不代表整体优化成功、最佳路线或长尾改善。

## 原理、输入与公平对照

复用[普通 CE seed42 最终 adapter](VLM_WEIGHTED_SFT_RESULTS.md)，固定原权重 BF16、SDPA、TF32 关闭、batch4、greedy max32。研究变量是相同视觉 token 中的图像内容分配，而非训练算法或识别文本注入。

| 条件 | 实际送入 processor 的画布（宽×高） | merged visual token | 用途 |
|---|---|---:|---|
| `whole` | 单整图 letterbox 896×896 | 1024 | 最强实际基线 |
| `double_whole` | 同一整图复制两次，各 896×448 | 512+512 | 双槽位/重复内容对照 |
| `text_region` | 整图 896×448＋预测文字区域 896×448 | 512+512 | 检验位置选择 |
| `random_matched` | 整图 896×448＋随机同形区域 896×448 | 512+512 | 控制裁剪面积和比例 |

画布保留内容比例，以 RGB(127,127,127) 填充，PIL BICUBIC 缩放，保存 lossless PNG。Qwen patch14、merge2 后，整图 grid 为 `[1,64,64]`，每半图 `[1,32,64]`；merged token=`prod(grid)/4`，因此每题实际恰好 1024。三种双槽位条件的问题、prompt、input IDs、grid 和 batch padding 逐题一致，只有 pixels 变化。单槽位平均总输入 token 1063.248，双槽位 1065.248；**等 visual token 不等于等总输入、FLOPs、有效信息或成本**。

预测器为 CPU `PP-OCRv5_mobile_det`，仅输出框和置信度，无识别文字输入 VLM。有效框置信度≥0.6，排名 `score*sqrt(clipped_bbox_area/source_image_area)`，按 bbox 字典序破同分，四边加 10% 外扩并裁到原图边界；无有效框时两种区域条件均回退整图。随机条件用稳定 image ID 哈希与 seed20261012，在合法范围均匀平移同宽同高框，不强制避开文字。选择器不用问题、参考答案、target 或已有错误分数；同一图不同 QA 共用位置。

代码入口：[检测器](../src/vlm_region/detect.py)、[ROI/随机框/letterbox](../src/vlm_region/views.py)、[多图编码与输入合同](../src/vlm_region/data.py)、[生成及缓存校验](../src/vlm_region/evaluate.py)、[非抢占调度](../src/vlm_region/pipeline.py)、[图像配对分析](../src/vlm_region/analysis.py)、[冻结配置](../configs/vlm_region_token_v1.json)。该新 letterbox 输入协议与历史 native-resize 87.112% 不同，历史分数不能作为本轮受控基线。

## 工程成本与失败观察

| 条件 | 纯生成 QA/s | 缓存视图读取＋预处理＋H2D＋生成 QA/s | 峰值 allocated / reserved GiB |
|---|---:|---:|---:|
| whole | 2.067 | 1.739 | 8.420 / 8.936 |
| double_whole | 2.061 | 1.744 | 8.420 / 8.936 |
| text_region | 2.083 | 1.764 | 8.420 / 8.936 |
| random_matched | 2.093 | 1.794 | 8.420 / 8.936 |

计时各剔除首 batch，保留 1,613 QA；两张 A100 上按整图/双整图和文字/随机两组 worker 顺序运行，资源记录不能证明严格独占或线上 SLA。启动器记录的完整 dev 评测＋分析壁钟 1929.34 秒（约32分9秒），含再次准入等待、模型加载和分析，排除之前的 61.03 秒 GPU 预检、检测及 CPU 准备。STATUS 起点沿用了预检开始时间，因此其 1989.93 秒（约33分10秒）包含预检；首个完整 worker 准入到最后 worker 完成为 1889.49 秒（约31分29秒），含模型加载、排除分析。三个时间的起点和覆盖范围不同。

CPU 检测 1,024 张唯一图，11,205 个框、28 张空检测；predict API 累计 554.518 秒，约 0.542 秒/唯一图，按 dev QA 摊销 0.343 秒/题。实际 4,096 个独立缓存画布的裁剪/letterbox/PNG 编码累计 174.072 秒（1.237/29.967/142.868）；完整单次 CPU 准备与 6,468 编码合同壁钟 768.682 秒，排除检测。共享画布及重复槽位的引用计时不能再当作物理准备成本相加。缓存 VLM 阶段吞吐未包含这些成本，当前无端到端加速或显存节省证据。

保存评分中，按绝对差超过 1e−12 计变化，区域相对单整图 79 题升、186 题降，其中 118 题从满分降至零分；另有一题 0.9 与 0.8999999999999998 为机器精度同分。下一步优先复用这些实际输入和预测检查：全图分辨率下降、框选错目标、局部图缺少上下文等仍是待核实假设，未人工完成机制归因。[图解学习页生成器](../tools/build_vlm_region_reader.py)可在本地重建原图、实际画布及保存预测对照；带原始图片的 HTML 不收入 Git。
