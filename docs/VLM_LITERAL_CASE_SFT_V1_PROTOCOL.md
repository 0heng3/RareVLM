# 完整词SFT：大小写口径与可学性对照

2026-10-23，新模型输出前登记。上轮原SFT/DPO均32步，每个128词错误只曝光2次，训练满分22/25、256词验证82.03125/82.421875%、native512=93.164063/92.832031%、保持均92.1875%，完整失败停止。刚做的只读诊断：128词GT大小写与负例风格不同112题；SFT48/DPO44题仍是原错误词、只换大小写。训练token目标区分大小写，评测canonical=NFKC/casefold/strip忽略大小写。这提示格式捷径，尚未证明为唯一原因。过去联合MLP虽拟合88/128却降低整图迁移，因此新实验必须分别检查拟合和泛化。

**单一主要变化。** 两新臂raw_case/canonical_case都只用SFT，从原uniform42精确5d8初始化、fresh Adam/RNG，不接训负Final。原128助手审核官方词区域、原256回放及同序列顺序完全复用。raw_case用原词标签；canonical_case只对128词训练标签做与既有评分相同的NFKC/casefold/strip，原target/原图片/提示/所有评测参考不变，256native回放标签不改。不训练DPO，不改其旧负例/参考，不将归一化文本伪装为原轨迹。字形纠正与单纯改大小写分开报告，大小写变化不是能力收益。

共同预算128更新、micro4/effective16、每步common4/hard4/common4/hard4；原32步数据顺序循环4次，即128困难题各8次、256回放各4次，共2048QA曝光/臂。LR2e-4、前8步warmup、全128步cosine、wd0/clip1/seed42，Final128为固定候选；step32仅固定训练诊断，不按dev选点。与历史32步的LR曲线/负例混合padding不同，不把历史差异全部归因步数；同128步两新臂才是大小写干预对照。大小写会改变BPE/token数，报告真实成本，不称等token/FLOPs。语言q/v144 FP32/1843200更新，BF16底座和FP32 head冻结、dropout0、TF32off、1024视觉上限与既有数据processor不变。

**验证数据修复。** 旧128拟合背景、旧256词验证、512native与64保持都完整保留且同帧旧初始预测复用。另从prediction-free4964源库存中原2304之外、答案词曝光0且词长>=5、源框高>=24/宽>=60的区域，按固定SHA取192候选，助手只看实际区域图/官方GT（不看任何模型预测或得分），逐图审查完整文字/标点/截断/可读性，取前128支持项作为新的内部词验证。若不足128则停止准备，不补旧验证或训练。新旧训练/验证原图、decoded pixel和词均隔离；新词图来自原SFT train_all，不能称原SFT未见图片/预训练未见。given-word-region任务不是无框定位，整图VQA不按答案裁剪。所有新图采用已验证的2px边及最短边<28时BICUBIC等比适配；展示放大不是新原生细节。该128是新内部质量审核集，不替换旧256或救回旧失败，不是专家标注或外部盲测。

初始模型只新增128新词验证生成；其他初始同帧只读复用。128词拟合在step32、Final128各生成128/臂；Final同时新词128+旧词256+native512+保持64，Final共1088生成/臂，外加step32的128。原数据/代码/输入/模型/包版本在GPU前锁定；CPU逐角色chosen/EOS标签SHA，实际每批核对。SFT使用EOS-aware sequence_logps后逐QA token均值；负例不前向/不算loss，无教师/偏好缓存。复用原加载/断点/生成/图像簇区间，不再审旧全局mask等。

**判定。** 拟合可学性预设为Final完整字面正确>=96/128，仅训练诊断，不算能力提升。主要外推证据为新128词验证对初始>=+3pp且6000次配对图像簇95%下界>0，native512对初始>=+.5pp且下界>0；native单/多词及rare1–5点保护>=-.5pp、64保持>=-.5pp，旧256完整词不劣点差>=-.5pp。候选若要支持大小写修复优势，还须对新raw_case在新词验证和native两域各>=+.5pp/正区间；只降低recase错误数不通过。两个新配置都报告，不用坏控制救成功。未通过则停止该配置，不扩大epoch/seed或加DPO。第一阶段通过任一臂才另评两臂原1617迁移，并保留原两域/强基线/罕见保护和三seed要求；新转写集收益不替代项目主目标。

训练每臂累计<=1800秒，评测每臂<=1500秒、allocated<=65GiB；共享空闲锁/零compute/40GiB/利用率<10%/3×15秒，不抢占其他任务，完整Adam/RNG/输入日志偏移断点/UUID恢复。单seed内部探索，置信区间条件于固定模型，不含seed稳定性。学习页用真实图、标签token和输出解释大小写捷径，区分旧错误、原始大小写和修复后结果。CV/科研/Agent/CI不改，不push。
