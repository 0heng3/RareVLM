# 连续低收益的原因：监督、目标与实际错误没有充分对齐

2026-10-18。仅分析已保存数据、预测与训练trace，0新GPU推理、0优化器更新。原科学源码、阈值、预测、权重与负结果不变。

最有证据的原因是实验设计与残余错误的对应不足。当前训练能更新，但这不等于新增监督提供了足够新知识，也不等于新增损失直接约束了仍然出错的决策。之前把“有错题”当作某个新目标的准入依据，机制验证不够，这是实验选择上的失误。

## 1. 多数新增监督是强起点已经答对的题

最新官方互补训练集600对/1200QA，初始只错46QA，准确率96.17%；45对未全对。正式800次配对曝光中，60次来自这些初始错对；1600次人工QA曝光中，仅61次（3.81%）是原始模型答错的QA。其余不等于没有训练价值，但针对剩余错误的信号占比较低。

前一轮只保留30条图像核验难例，难例曝光17→400、最多重复15次，却在独立screen上3纠正/3新错。重复强化少量错误没有证明能够迁移到新图；不能据此直接定为典型过拟合，因为该轮未取得固定Final训练题生成拟合率。

## 2. 新排序项没有直接约束两图各自的判定边界

代码：`src/vlm_complementary_rank/loss.py`。令`m = logit_yes - logit_no`，新增项为：

`softplus(-(m_yes图 - m_no图))`。

同一加性yes偏置在差中相消，只表示共同平移不能降低这个loss，**不表示这个loss会惩罚或阻止共同平移**。原CE仍提供分类约束；排序项没有补足绝对位置约束。若一对的两张图都偏向yes，依然可以把正图排在负图前、得到很小的排序损失。

第177步实际训练读出，问题均为“Is there a vacuum cleaner in the picture?”：

| 图像人类标签 | 小写yes/no间隔m | 条件二元判定 |
| --- | ---: | --- |
| yes | 7.125 | yes |
| no | 0.250 | yes |

差值6.875对应排序loss仅0.001033。第二张仍在错误一侧，排序项却已经接近满意。

图片是原图展示，不是注意力；表格是训练第177步的teacher-forcing首token读出，不冒称该步自由生成或Final独立评测结果。大小写token别名及其他词也可能影响自由生成。

实际800次在线配对曝光，788次（98.5%）已严格排序正确；其中64次未达到条件二元双正确，52次（81.25%）却已经排序正确。694次rank loss<0.01；83.125%的gap>5，排序导数系数sigmoid(-gap)<0.0067。加权rank占累计目标值5.11%，不是参数梯度份额。9次严格逆序、另3次并列，不能把12次均称逆序。

这是随训练变化且含重复曝光的记录，不是800个独立样本、固定Final性能或独立验证集归因。新screen没有保存首token logits，所以尚不能证明其全部剩余错误属于同一阈值机制。

## 3. 实际收益很弱，不能只归咎门槛严格

最新候选：QA95.3125→95.5078125、pair90.625→91.015625；5纠正/4新错，净1。对相同数据CE控制，两主指标均0pp，只交换1个纠正和1个新错。Text对CE仅+0.019531pp。

yes切片净+4QA（+1.5625pp），no切片净−3QA（−1.171875pp）。Text高频−0.7377pp，原保护失败。仍以类别取舍为主的观察模式，没有足够证据证明额外视觉区分力。

筛选初始24QA错误，净纠正6意味着至少消除25%的原错且不新增错，要求确实不低。但候选只净1、对CE净0；放宽置信区间或保护门槛也不会把它变成有实质幅度的改进。

## 4. 哪些因素已证实，哪些尚未隔离

| 因素 | 证据与边界 |
| --- | --- |
| 监督与难度覆盖 | 较强证据：新标签更可靠但96.17%已答对；旧30难例重采样未迁移。不能把全部源标签称脏数据。 |
| 目标函数选择 | 较强证据：主要在线二元错误已满足排序，新项对它们约束弱；不等于所有排序学习或SFT无效。 |
| 框架/数值链路 | 目前不支持为主因：两臂200步自然完成、FP32权重改变；历史真实32QA正控制可拟合100%，仅说明链路可学。旧精度舍入与路径缺失确实存在但已修复，不能继续解释当前零增益。 |
| 更新强度/适配容量 | 尚未隔离：LR2e−5、200步、仅语言q/v LoRA可能影响修正；不能直接断言加LR、加epoch或解冻视觉必然有效。旧6小时候选也只净2，缺少盲加时长依据。 |
| 泛化/记忆 | 未完成固定Final训练难例的实际生成对照，不能据在线loss就断言已经学会并过拟合。 |

## 5. 下一步应测什么，暂不新增训练

下一次训练前，先用固定初始/Final checkpoint、相同训练错题及已用screen做一次零更新读出，区分：①标签/图像依据问题；②两图逆序；③已排序但共同位置错；④训练错题仍不会；⑤训练已纠正但未迁移。实际生成与条件二元读出分开。

对每对令`d=m_yes图-m_no图`、`c=(m_yes图+m_no图)/2`，条件二元双正确需要`d>0`且`abs(c)<d/2`。目前只有在线trace，不能把它当作固定Final的结论。若做共同阈值诊断，参数仅在训练侧拟合、冻结后看已用screen；不能用screen挑最佳阈值，更不能把推理校准包装成新增视觉能力。

不继续该rank分支加λ/epoch，不直接改名DPO/GRPO再跑。新方法只有在其优化信号确实覆盖已确认错误机制后再立项；不追加重复工程审查，不修改原负结果或简历。
