# 原始SFT真实错误监督挖掘 v1：执行前固定协议

2026-10-20登记。上一轮EOS专项只得到5对合格样本，低于原32对门槛；原协议和负结果保持。本研究针对不同问题：原始SFT起点实际上还不会哪些高共识、低监督频次的TextVQA题？不使用退化Final当矿工，不依赖GT前缀EOS排序，也不只收多词前缀。

## 数据与划分

仅原`train_all`、原文答案至少8/10票、1–6词、规范化监督答案频次1–5。频次是训练答案曝光代理，不是实体类别或预训练知识。排原dev/final、上一区域训练1600图、当前匹配训练/保持、512分层诊断、旧512 EOS矿池、区域偏好保持及128/256迁移图与完全相同像素。具体文件清单和哈希进入PLAN。初始模型已训练过train_all；本研究不声称初始未见或正式盲测。

固定SHA排序，同图/同像素只保留一题。单词、多词两层各选768题：每层前512划为训练池、后256划为独立验证池。共1024训练候选、512验证题、1536唯一图；划分在新生成之前锁定，不按错误、CE或候选表现重排。两个GPU分片各768题，包含512训练、256验证。验证池不用于挖掘训练偏好、人工挑训练样本或回填训练。

## 模型与实际生成

从原始uniform SFT42 adapter加载，复用已验证的原BF16底座、FP32 q/v和输出头、1024视觉上限、batch4、raw greedy32及原TextVQA评分。每题保存实际预测、输入记录、生成长度及资源记录。生成仅提供原图和问题，答案只作后评分。0optimizer、0新adapter，前后LoRA身份必须不变。已通过的加载/保存/精度诊断不重做。

## 偏好候选与可见证据

只从1024训练题取：完整参考得1分、真实生成非空、原VQA分<=.3且chosen-rejected>=.7，生成非pad长度<32（排预算截断）。缺词、前缀、额外上下文、其他错词只按文本关系作初始标签，不冒充视觉因果或全量人工真值。保留所有非合格结果，不能人工截短或生成伪负例。

算法合格样本按独立SHA排序，最多先逐图审查64对；要求完整chosen的可见证据、问题对应对象及rejected确实较差，含糊/看不清/参考不唯一的排除。至少32对经可见证据支持，才可另登记同数据SFT与CE+DPO短实验；未达就停止，不降低门槛、不扩大本轮数据预算或凑EOS旧门槛。单词/多词均可进入，但报告各数量。助手审查不是专家重新标注，原参考与评分不修改。

## 后续决策与资源

本脚本不自动训练；训练需另行固定同初始/同数据/同顺序/同32步、完整CE强控制、reference口径和独立验证/保持。验证结果仅是本轮初始基线，不用于反选训练QA，不以挖掘数量或CE声称能力提高。主VQA、罕见和跨任务保持门槛不改，不从负Final接训或用PPO/GRPO名称替代数据证据。

先CPU真实1536推理编码与来源锁，再经共享UUID队列3次15秒空闲/40GiB/<10%/零其他compute准入。每worker生成active上限900秒，已有任务不终止；实际计时后更新ETA。所有文件持久化，已完成batch可按原身份和顺序恢复，不重复生成。最终仅归档实际错误与数据准入状态，无简历提分声明。
