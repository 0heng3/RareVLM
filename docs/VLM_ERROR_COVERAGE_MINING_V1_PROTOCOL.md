# 扩大原生错误覆盖 v1：固定新训练池与验证（0更新）

2026-10-21登记。上一轮GRPO仅17题策略信号/65种题目回答组合，训练仅6/32满分，未超匹配SFT；停止在同32题换损失。新任务收集更多独立图像、可核实的原生问题真实错误，支持后续覆盖实验。采样量/数据准备不是模型能力提升。

## 事前固定输入

原始uniform SFT seed42（不接训任何负Final），相同BF16底座/FP32语言qv LoRA/冻结FP32head/1024视觉预算、显式raw greedy32/batch4。只使用原train_all，排原dev/final、前述区域/回放/scope/readout/pixel矿池与诊断、旧1536矿池、原生双问128、新GRPO512及相同pixel。公开初始SFT训练白名单，不能称初始模型未见；近重复和预训练重叠未知。

候选原GT至少8/10票，答案1–6词；train_all规范化监督频次1–20（较旧1–5明确扩大，分1–5和6–20报告，不偷换旧rare定义）。原始精确像素去重。可用新多词图仅约522，单词约5381；不是全池噪声统计。

事前固定512验证（256单词/256多词）与训练3072（2816单词/256多词），共3584唯一图/QA。先依SHA分配稀缺多词验证256/训练256，再分配单词验证256/训练2816；各桶同pixel只能进入一个，不看预测选题。训练组成不代表自然分布，评测切片与频次必须分列。CPU真实编码全部3584输入，记录input ids SHA/grid/token，不截断。

## GPU与存档

两worker按完整4题批次交替分片，每片1792QA，按全局批次顺序合并；后续同组候选可以沿用同一四题批边界，不用奇偶QA重组或跨fold混批。每条保留真实completion_ids、EOS/长度删失、原始文本与VQA分；不decode再分词代替实际动作，不伪造EOS。GT只在生成后评分，全部图像/问题输入单独编码验证。

每batch完整保存、可从同来源/相同GPU UUID恢复。每worker1500秒活动预算（非承诺ETA）/allocated65GiB；共享零compute/40GiB/3×15秒准入，不终止其他任务。等待已提交纠错曲线完成后再准入，绝不改旧source/权重/预测。

## 候选、语义与后续准入

仅训练fold：原greedy naturally terminated，score<=.3，原target consensus−score>=.7，规范化文本不同才列候选；长度删失单列，不凑负例。按旧text_relation区分缺词/额外上下文/不同文本，再报告单词近似拼写候选（编辑距离仅分类代理，不当真值）。不按验证错误回填训练。

原图审核按固定训练候选SHA前256查看；必须确认问题指代/可见范围及完整答案，排有效简称、忠实完整短语、标点/变音符、图像边缘截断与其他语义不确定。VQA低分不自动等于视觉错误。原标签/分数/候选snapshot保持，审核独立存档。

未来训练的必要条件为至少128个有可见支持的不同训练图错误，至少2种审核后错误类型各16条；每个规范化target最多2条。未满足则报告不足、不改阈值或扩温度/换Final补错误；不得将自动分类视为128已核实。此轮不自动训练。

数据达到条件后另预登记新强SFT的“覆盖128题vs重复32题”预算匹配研究：同原始起点/完整监督曝光与回放/学习率/步数，只改变错误覆盖，记录每步CE/策略等实际项与输入、独立Final评测。具体日程在新训练前冻结，不能提前当已执行。是否增加RL取决于新强SFT的真实学习/迁移和额外可信奖励，不因GPU空闲自动跑。新验证对初始至少+.5pp/正95%图像簇下界、rare与保持保护及后续原主任务标准不降；旧GRPO512失败不回写，语义图解不是重评分或成功救援。
