## 唯一因素与初始化

两组均使用原SFT42、FP32 q/v LoRA1843200和普通完整CE，另加同一个2048→32→2048无偏置残差模块，共131072新参数；总可训练1974272。f(x)=cast_dtype(x_fp32 + W_up GELU(W_down x_fp32))。down用独立CPU seed42初始化，不扰动主RNG；up全0，起点逐值相同。返回输入原dtype，参数和加法FP32；没有残差门控系数/搜索。

- visual：在视觉编码器/原merger输出后、插入语言序列前适配每个视觉token。原ViT与原merger保持冻结，**不是视觉全参微调、Q-Former或解冻merger**。
- readout：在语言最终隐藏态进入原FP32冻结head前适配。head裁剪前执行，保持同残差算式与参数量；该对照不是原q/v-only，避免把多参数本身归因为视觉位置。

位置决定处理的token和梯度路径，不能声称两组计算量逐算子相等。记录两组active时间/显存。两组均真正新训，旧普通SFT32仅作为额外复用参照。

## 验收与边界

各Final只生成原28区域题与64保持题，均是训练白名单，仅图像与本轮回放分离，不叫独立泛化。视觉候选短学习需比初始净>=4QA、双框全对+2、保持总分下降<=1且新增降分<=2；扩大还需比新readout控制多>=2QA与2pair，保持总分不比控制低超过1。对旧SFT及两新位置报告所有纠正/新增错/同答，不把loss/梯度或参数成功保存当能力提升。

不自动200步/扩seed/主benchmark/简历更新；原主VQA门槛保持。失败不从这32步断言所有视觉适配无效，或直接换RL名称。只有提出新可区分假设才另立项。
